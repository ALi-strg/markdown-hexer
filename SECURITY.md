# Security Policy

## Reporting a vulnerability

If you've found a security vulnerability in Markdown Hexer, please use **GitHub's private vulnerability reporting** instead of opening a public issue:

1. Go to <https://github.com/ALi-strg/markdown-hexer/security/advisories/new>.
2. Describe the vulnerability, how to reproduce it, and (if known) the impact.

Reports are handled privately and acknowledged. Please don't disclose the issue publicly until a fix is available — the project is maintained by one person, so this window may take a while.

## Scope

This policy covers the Markdown Hexer application itself. General vulnerabilities in upstream components (egui/eframe, winit, pulldown-cmark, egui_commonmark, the `image` crate, rfd, …) should be reported to those projects directly. The 2.0 app has no webview and no JavaScript runtime.
