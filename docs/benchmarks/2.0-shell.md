# 2.0 native shell startup

Measured on the ticket 02 worktree with the release profile.

- Windows 11 Pro 10.0.26200, AMD Ryzen 7 9800X3D, 61.6 GB RAM,
  NVIDIA GeForce RTX 4070 Ti SUPER, Samsung 990 PRO NVMe.
- Rust 1.98.0. Non-admin session, Defender active, warm disk cache.
- Harness: `app/tools/startup_bench.py --runs 20`, fixture
  `app/tests/fixtures/startup.md`, release binary 5.59 MB.
- T1: first visible titled window of the launched process, polled through
  Win32 `EnumWindows`/`IsWindowVisible` at 2 ms.
- T2: app timestamp when the first frame containing the rendered document is
  submitted. eframe paints that frame before showing the hidden window, so T1
  is the first moment the readable frame is on screen.

| Metric | median | p95 | min | max |
| --- | ---: | ---: | ---: | ---: |
| T1 visible (external) | 125.0 ms | 141.0 ms | 109.0 ms | 234.0 ms |
| T2 readable frame (internal) | 108.5 ms | 116.3 ms | 102.9 ms | 121.2 ms |

The Windows readable gate (p95 ≤ 200 ms) passes. One T1 outlier at 234 ms was
observed; the other 19 runs were ≤ 157 ms in the preceding run.

Cold-disk startup was not measured: dropping the file cache requires admin
rights this session does not have. The ≤ 700 ms cold-disk gate remains
unverified.
