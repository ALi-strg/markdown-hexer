# Public repository with closed external contributions

The repository went public with a deliberately asymmetric contribution policy, documented in CONTRIBUTING.md: **issues are always welcome** (bug reports are the reason for going public, alongside unlimited CI action minutes), while **pull requests from outside the Collaborator circle are closed without merging**. The codebase is evolving too fast — internal structure and even the document model shift between releases — for external PRs to land before they go stale, so the sole author absorbs all code work for now. Trusted people ("good friends") are granted Collaborator (Write) access and open Pull Requests into `main` like anyone, but `main` is branch-protected to require a passing CI run and an approving review from the Code Owner (`* @ALi-strg` in `.github/CODEOWNERS`), so the author remains the last instance on every merge and every Release — mirroring the GitLab "Developer role + code-owner approval" workflow the author is used to from work. Flathub, which the private-repo state used to block, remains deferred by choice (ADR-0006). The policy is temporary: it will be revisited — and the README updated — once the codebase stabilizes. A self-hosted or bot-driven PR auto-close was rejected as hostile and unmaintained; the human reply closes external PRs instead.
